# no-ai-slop

Repo for stripping AI-writing patterns from text before it hits the web.
Based on blader/humanizer (34 patterns). Not a style guide. A filter.

## What's here

- `before.md` — sample AI-generated text with the tells intact
- `after.md` — same text after the 34-pattern audit (work in progress)
- `references/` — links back to `~/.hermes/skills/creative/humanizer/`

## The 34 tells (short list)

Em-dash overuse. Copula avoidance ("serves as"). Promotional fluff ("vibrant", "groundbreaking"). Vague attributions ("Industry observers"). "-ing" phrases that fake depth. Rule-of-three lists. False "from X to Y" ranges. Chatbot openers ("Great question!", "I hope this helps!"). Generic upbeat closers ("the future looks bright"). And 25 more — read the skill.

## How this repo is used

Pull a file in. Run the audit. Rewrite. Audit again ("What still looks AI?"). Rewrite once more. Push.

No AI slop leaves without a second pass.
